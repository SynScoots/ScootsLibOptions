## Description ##

This is a library addon which is required to build the options panels for a number of my other addons. By itself it has no baseline effect on the game interface.

## Installation ##

Download this repository, then extract the `ScootsLibOptions` subdirectory from the `src` directory into your `World of Warcraft/Interface/AddOns` directory.
